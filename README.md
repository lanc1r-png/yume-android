# Yume для Android

Неофициальный нативный клиент библиотек Lib (Kotlin, Jetpack Compose, Material 3).

Сейчас готово: каркас, пять вкладок, настройки (платформа, тема), иконка.
Работает только платформа «Манга» (в разработке); «Аниме» и «Ранобэ» помечены «Скоро».

## Сборка

APK собирает GitHub Actions при каждом пуше в `main`.
Скачать последнюю сборку: раздел Releases → `latest` → `Yume-debug.apk`.
